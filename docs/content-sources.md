# 內容來源與公開範圍

此文件協助後續維護者追溯網站內容。根目錄原始 PDF 是本機參考素材，公開網站只使用 `site/` 中的檔案。

## 編輯原則

- 個人介紹、工具、工作經歷與 Email 取自提供的履歷，重新整理為適合網站閱讀的摘要。
- 不發布原始履歷，不呈現家庭敘述、電話、居住地或成績單。
- 學術背景僅列學校與系所，不推定目前仍在學或已畢業，也不自行新增職稱。
- 國衛院研習年份採履歷工作經歷與「2023 國衛院暑期研習成果報告」的一致年份 2023；不採履歷研究段落中不一致的 2022 日期。
- Azure 證照名稱採獨立證書上的 Azure AI Fundamentals，對應提供的 AI-900 文件，不沿用履歷的 AI-500 誤植。
- AI CUP 首頁成果採獨立獎狀的「前標」，不把履歷內附的名次與不同獎項標準混合使用。
- 心臟衰竭模型圖表數值出自原報告第 11 頁的平均模型預測表現；長條從 0 起始，上限為 1，不使用截斷軸誇大差異。
- 報告與壁報的模型設定不同，保留各版本；網站不將各版本的效應值混用。
- 課程或研究成果保留其限制，不宣稱已通過外部驗證或投入臨床使用。
- 下載文件為提供的原始作品／證明副本，未更動內文。可能包含作者、學號、機構、研究協作者或證照驗證資訊，皆屬文件原有內容。家庭資料所在的兩份履歷完全排除。
